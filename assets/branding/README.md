# Gem Cutter 品牌资源

Gem Cutter 的 Logo 由本地原稿 `cutter.svg` 延展而来：蓝色切面代表从复杂信息中提炼价值，青绿色上升箭头代表热点趋势、证据积累和机会增长。

## 文件选择

| 文件 | 用途 |
| --- | --- |
| `gem-cutter-mark.svg` | 透明底彩色主标，适合深色或中性背景 |
| `gem-cutter-mark-light.svg` | 浅色背景主标，使用较深配色提高对比度 |
| `gem-cutter-mark-ink.svg` / `gem-cutter-mark-white.svg` | 深墨色 / 白色单色标志 |
| `gem-cutter-lockup.svg` | 深蓝底横向 Logo，包含 Gem Cutter 字标和副标 |
| `gem-cutter-lockup-light.svg` | 白色或浅色底横向 Logo |
| `gem-cutter-icon.svg` | 深色应用图标 |
| `gem-cutter-icon-light.svg` | 浅色应用图标 |
| `gem-cutter-icon-small.svg` | 16～24 像素优先使用的原稿比例图标 |
| `gem-cutter-banner.svg` | README 和项目介绍页使用的白底横幅 |
| `gem-cutter-preview.svg` | 品牌资源预览板 |

## 使用规范

- 独立标志保持原始纵横比，不拉伸、旋转或拆分切面顺序。
- SVG 画板已经包含安全留白；外部排版至少再保留约一个箭头宽度的周边空间。
- 浅色背景使用 `-light` 版本；深色背景使用主版本、深色横版或白色单色版本。
- 16～24 像素场景优先使用 `gem-cutter-icon-small.svg`；它保留原稿完整切面，只增加深色圆角底板。
- 横向字标建议宽度不小于 220 像素；空间不足时只使用独立标志。
- README 使用 `gem-cutter-banner.svg`，不要把带圆角底板的应用图标拉伸成横幅。
- Logo SVG 自包含，不依赖外部字体、图片、滤镜或网络资源。横向字标中的文字使用系统字体，品牌展示板和 README 横幅可直接在浏览器中渲染。

## 原稿关系

`gem-cutter-mark.svg` 保留原稿的切面结构和三色渐变。其他版本只调整背景适配、单色处理和排版组合，不改变核心图形的识别特征。
